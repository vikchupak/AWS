# Protocols

| **AWS Service**                 | **Protocol**  | **Typical Use**                                                           | **OS**      |
| ------------------------------- | ------------- | ------------------------------------------------------------------------- | ------------------- |
| **Amazon EFS**                  | **NFS**       | Linux workloads; shared file storage                                      | **Linux**           |
| **FSx for NetApp ONTAP**        | **NFS / SMB** | Mixed Linux/Windows; enterprise file storage                              | **Linux / Windows** |
| **FSx for OpenZFS**             | **NFS**       | High-performance Linux/Unix workloads; workloads needing OpenZFS features | **Linux / Unix**      |
| **FSx for Windows File Server** | **SMB**       | Windows workloads; Active Directory integration                           | **Windows**         |
| **FSx for Lustre**              | **Lustre**    | Linux/HPC/ML/high-performance workloads                                   | **Linux**           |
