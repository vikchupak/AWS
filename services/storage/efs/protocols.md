# Protocols

| AWS service                     | Main protocol | Typical use                      |
| ------------------------------- | ------------- | -------------------------------- |
| **Amazon EFS**                  | **NFS**       | Linux workloads                  |
| **FSx for Windows File Server** | **SMB**       | Windows workloads                |
| **FSx for Lustre**              | Lustre        | High-performance computing       |
| **FSx for NetApp ONTAP**        | **NFS + SMB** | Mixed Linux/Windows environments |
