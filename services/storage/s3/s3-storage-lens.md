# S3 Storage Lens

* **Amazon S3 Storage Lens** → provides **visibility and analytics** across S3 storage.
* Shows metrics such as:

  * Storage usage
  * Object counts
  * Versioning status
  * Storage trends
* Can analyze data by **account, Region, bucket, or prefix**.
* Provides **cost optimization and data protection recommendations**.
* Can **export metrics** for analysis with tools like Amazon QuickSight, Athena, or Redshift.
* Useful for identifying issues across many buckets, e.g. **S3 buckets without versioning enabled**.
* Available in **Free and Advanced tiers**.
